# Imágenes del sistema

La interfaz ya tiene espacios reservados para imágenes. Basta con copiar el
archivo con el nombre indicado; mientras no exista se muestra un marcador gris.

| Archivo | Dónde aparece | Tamaño sugerido |
|---------|---------------|-----------------|
| `logo.png` | Barra de navegación, login y comprobantes | 256 × 256 px, fondo transparente |
| `login.jpg` | Panel lateral de la pantalla de inicio de sesión | 1200 × 1600 px (vertical) |
| `bienvenida.jpg` | Portada pública (página de inicio) | 1600 × 900 px |
| `productos/{SKU}.jpg` | Catálogo de inventario y punto de venta | 600 × 600 px (cuadrada) |

Ejemplo: la foto del juguete con SKU `JUG-004` va en `productos/JUG-004.jpg`
(también se aceptan `.png` y `.webp`).
